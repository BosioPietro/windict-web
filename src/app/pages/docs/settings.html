Settings

Open the tray menu and choose Settings…. Changes apply right away.

General

Start with Windows Runs WinDict when you sign in. Also in the tray menu.
Show above Start Opens the card on top of Start and Search. Only in the installed copy: see Above the Start menu.
Check for updates Once a day. When there's a new version, the tray icon shows a dot and its menu has Update app.
Language The language WinDict is shown in: English, Italiano, Español or Français. At first, the language of Windows, if WinDict has it.
Shortcuts The keys that look up and translate, and at first. Click one and press the new keys; keeps the old ones.

Card

Theme System, Light or Dark. With System, the card follows Windows, and always takes its accent color.
Text size From 80% to 200%. Also , or Ctrl and the mouse wheel on the card.
Definitions Senses shown per part of speech, from 1 to 10. 4 at first.
Synonyms Similar words under each part of speech, from 0, which hides them, to 12. 6 at first.
Examples Sentences showing each sense in use.
Animations At first as Windows has them, under Accessibility → Visual effects. Turn on or off to override it.

Lookup

Online dictionary For pronunciations, and words the built-in dictionaries lack. Translations need it on.
Languages The dictionaries words are looked up in. English is built in; choosing any other language downloads its dictionary, once.

Read selections

How WinDict reads what's selected:

  • Direct only, the default: reads the selection directly, through UI Automation. It opens faster, but misses selections in apps that can't be read that way. Switch to Automatic if words go missing.
  • Automatic: reads the selection directly, and copies it in apps where that isn't possible, putting back what was on the clipboard. Works in every app.
  • Clipboard only: always copies the selection, which is slower. Try it if an app gives the wrong text.

Translation

Default languages Translated from and into when the language can't be told: English into Italiano at first.
MyMemory email Raises MyMemory's daily limit on free translations. It's sent only to MyMemory, with the text translated.

The settings file

The settings are stored in %APPDATA%\WinDict\config.json. To edit the file by hand, use Open config.json at the bottom of the settings window, then Reload settings in the tray menu. 

{{ '{' }}
  "hotkey": "Alt+D",
  "translate_hotkey": "Alt+T",
  "theme": "system",
  "max_definitions": 4,
  "max_synonyms": 6,
  "show_examples": true,
  "zoom": 100,
  "selection": "direct",
  "online_lookup": true,
  "languages": ["en"],
  "translate_from": "en",
  "translate_to": "it",
  "check_updates": true
{{ '}' }}

Shortcuts are written as in "Ctrl+Alt+D" or "Win+Shift+F1": one key, with at least one of Ctrl, Alt, Shift or Win.
